# 席替えアプリ（GAS）

## できること

- 教室の縦・横の席数を設定（例：縦4 × 横7 = 28席）
- 基本名簿の登録
- 前席希望（名簿で名前の前に `★` を付ける）
- 「くっつける」「離す」組合せ条件の設定
- 条件を加味した席替え案を3案自動作成
- 前回と同じ席の児童をピンクで表示
- 選んだ案を次回の比較用「前回の座席」として保存
- 作成した案を手動で入れ替え（2人の席を順にタップ）
- 一時退避へ出してから、空席に戻す段階的な入れ替え
- 完成した席替え表のPDF出力（印刷画面から「PDFに保存」）
- 席替え履歴の保存・再表示・PDF出力（最大30件）
- 基本条件と今回だけの条件を分けて管理
- 利用者ごとの専用スプレッドシートへデータを自動保存

## 導入方法

1. Google ドライブで **新規 → その他 → Google Apps Script** を開く。
2. `Code.gs` の内容を貼り付ける。
3. HTML ファイルを追加し、名前を `Index` にして `Index.html` の内容を貼り付ける。
4. 保存後、**デプロイ → 新しいデプロイ → ウェブアプリ** を選ぶ。
5. 配布する場合は、実行ユーザーを **ウェブアプリにアクセスしているユーザー** に設定し、Googleアカウントでのログインを必須にします。
6. URLを開いた初回に許可すると、その先生のGoogleドライブに **席替えアプリ データ** という専用スプレッドシートが自動作成されます。

## 補足

- 「くっつける」は上下・左右に隣接することを優先します。
- 「離す」はマンハッタン距離3以上（例：横に3席以上離れる）を目標にします。
- 条件が多すぎると全てを満たせない場合があります。その場合も、最も条件に近い案を表示します。
- 作成後は、入れ替えたい2人の席を順にタップすると手動で交換できます。調整後に「この案を前回の座席として保存」を押してください。
- 一時退避を使うときは、席をタップして「一時退避へ」を押します。戻すときは、一時退避の名前をタップしてから空席をタップします。
- 名簿・基本条件・今回だけの条件・前回座席・履歴は、各先生の専用スプレッドシートに保存されます。
- 「基本設定」は次回以降も引き継ぎます。「今回だけの条件」は前回座席として保存した時点で自動消去されます。
